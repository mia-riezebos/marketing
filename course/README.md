# Marketing, launch, and operator course

A modular beginner course. It teaches marketing, positioning, distribution, being found, measurement, and how to work with agents without giving up judgment.

This folder is content for a later web app. It is not the app. Do not add SvelteKit, a repo, or a deploy from these files alone.

Written 8 November 2026 (Europe/Amsterdam) from a verified source corpus. The private research archive stays in `/workspace/course-research` and is not bundled here.

## How a reader should use it

Do one lesson. Stop at “You’re done when.” Come back later. There is no streak and no daily quota.

Times under each title are estimates, not assignments.

## Design rules for a later app

- Comfortable line length, generous spacing, readable type
- Show takeaway, time estimates, and the next micro-action near the top
- Show “You’re done when” before optional depth
- Mark hypothetical examples so they cannot be read as results
- Mark author claims separately from methods and findings
- Show item-level credits and a full source library
- Store progress only in the browser unless the reader asks for more
- No streak counters, no “don’t break the chain”

## What this course will not do

It will not ask you to spend money, connect an ad account, publish, or send unsolicited messages. Sharp tactics are taught with costs and risks. Their exercises stay on paper.
